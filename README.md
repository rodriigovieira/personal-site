# rodrigorodrigues.dev

Personal site and portfolio of Rodrigo Rodrigues. Static [Astro](https://astro.build) site, English at `/` and Portuguese at `/pt/`.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs dist/
```

All copy and projects live in `src/data/content.ts`. App icons and screenshots are in `public/img/` (`<id>-icon.webp`, `<id>-0..2.webp`).

Deployed on Vercel (`vercel --prod`).
